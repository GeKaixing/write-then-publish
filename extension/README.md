# 写了就发自动发布扩展

一个极简 Chrome MV3 扩展，把「写了就发」当前图文卡片自动填入小红书、微信公众号、抖音、小黑盒的发布页。

## 安装

1. 打开 Chrome，进入 `chrome://extensions/`
2. 打开右上角「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择本目录 `extension/`

安装后如果页面显示「扩展未连接」，请在 `chrome://extensions/` 点击「写了就发-自动发布」卡片上的刷新图标，再强制刷新「写了就发」页面；看到「扩展已连接」后再发布。

如果在刷新扩展前页面已打开，控制台可能出现 `Extension context invalidated`，这是旧页面的扩展上下文失效提示。从 1.0.7 开始，扩展安装或更新时会自动刷新已打开的小红书、公众号、抖音、小黑盒标签页，把旧脚本替换掉，不再需要手动逐个关闭。

「写了就发」源页面仍然需要手动 `Cmd+Shift+R` 强刷一次，避免编辑器里未保存的内容被自动刷新丢掉；看到顶部显示「扩展已连接」后再发布。

从 1.0.8 开始，源页面标签页信息会写入持久存储，即使扩展的后台 Service Worker 被系统回收，也能把自动填入结果回传；如果 60 秒内仍没收到回执，源页面会提示检查平台页是否已登录。

从 1.0.9 开始，公众号图片上传改用兼容新版编辑器的输入框查找，并在触发上传后等待缩略图出现；如果上传没有开始，会自动重试并带回公众号页面上的错误提示。

从 1.1.0 开始，新增小黑盒图文发布：打开小黑盒图文编辑器后自动填入标题、正文，并通过图片区拖放事件上传最多 9 张图片。

## 使用

1. 用 `npm start` 打开写了就发（必须走 `http://localhost:5173` 或 `http://127.0.0.1:5173`）
2. 在图文卡片模式生成卡片
3. 点击顶栏「小红书 / 公众号 / 抖音 / 小黑盒」按钮
4. 扩展会打开对应平台发布页，自动填入图片、标题和描述（公众号会填正文）
5. 确认登录状态和内容后手动点击发布

填写完成后，源页面的状态栏会收到成功或失败回执。

## 说明

- 只在图文卡片模式提供发布按钮，长文模式暂不支持
- 标题取当前项目第一行正文，描述取当前项目正文（自动去除 Markdown 标记）
- 任务 15 分钟内有效，过期会自动清理
- 平台页面只做自动填入，不会自动点击发布


## 版本号

扩展版本与网页端统一，由仓库根目录 `package.json` 管理。更新后运行：

```bash
npm run sync
```
