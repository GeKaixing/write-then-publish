# 写了就发 · Obsidian 插件

「写了就发」的 Obsidian 桌面插件版。功能与网页版一致：图文卡片自动分页、长文排版、导出 PNG / ZIP，数据保存在插件数据目录，导出文件写入当前活动笔记所在的仓库目录。

## 安装

1. 把本目录全部内容复制到仓库的 `.obsidian/plugins/write-then-publish/`。
2. 在 Obsidian 设置中启用社区插件，然后启用「写了就发」。
3. 使用命令面板执行「打开『写了就发』」。

## 命令

- 打开「写了就发」：打开编辑器面板。
- 将当前笔记导入「写了就发」：读取当前活动笔记，自动导入其中的图片引用。

支持 `![[图片.png]]` 短名引用和 `![](附件/图片.png)` 路径引用；短名图片会自动在整个仓库中按文件名查找。

## 与网页版同步

网页版与插件共享 `index.html`、`src/app.js`、`src/styles.css` 和 `vendor/` 下的资源。修改网页版后，在项目根目录运行：

```bash
npm run sync:plugin
```

脚本只覆盖共享资源，不会改动 `main.js`、`bridge.js`、`overrides.js` 等插件专属文件。
